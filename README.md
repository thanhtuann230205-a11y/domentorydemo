# DormSpace Frontend Demo

Bản demo tĩnh dành cho khách chưa đăng nhập. Không cần Java, MySQL hay Docker.

## Chạy nhanh

Mở `index.html` bằng trình duyệt, hoặc trong VS Code dùng extension Live Server.

Có thể triển khai nguyên thư mục này lên GitHub Pages, Cloudflare Pages, Netlify hoặc bất kỳ static hosting nào.
